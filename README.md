# Python Projekts Bibliotēka

1. math.sqrt(x)
Aprēķina skaitļa x kvadrātsakni.
Piemērs: sqrt(25) = 5
Izmanto ģeometrijā un Pitagora teorēmā.

2. math.pow(x, y)
Aprēķina x kāpinājumu pakāpē y.
Piemērs: pow(2, 10) = 1024
Alternatīva operatoram **.

3. math.floor(x)
Noapaļo decimālskaitli uz leju līdz tuvākajam veselam skaitlim.
Piemērs: floor(7.9) = 7

4. math.ceil(x)
Noapaļo decimālskaitli uz augšu līdz tuvākajam veselam skaitlim.
Piemērs: ceil(7.1) = 8

5. math.pi
Matemātiskā konstante PI (3.14159…).
Izmanto apļa laukuma un apkārtmēra aprēķinos.

6. math.factorial(n)
Aprēķina skaitļa n faktoriālu (n! = n × (n-1) × … × 1).
Piemērs: factorial(6) = 720

7. math.log(x, bāze)
Aprēķina logaritmu.
Bez bāzes — dabiskais logaritms (bāze e).
Ar bāzi 10 — decimāllogaritms.

8. math.sin() / math.cos() / math.tan()
Trigonometriskās funkcijas.
Lieto leņķus radiānos.
Izmanto fizikā un ģeometrijā.

9. math.radians() / math.degrees()
Pārvērš grādus radiānos (radians) vai otrādi (degrees).
Nepieciešams trigonometrijā.

10. math.gcd(a, b)
Aprēķina divu skaitļu lielāko kopīgo dalītāju.
Piemērs: gcd(48, 18) = 6

11. math.fabs(x)
Atgriež skaitļa absolūto vērtību kā decimālskaitli.
Vienmēr pozitīvs rezultāts.

12. math.exp(x)
Aprēķina e pakāpē x, kur e ≈ 2.718.
Izmanto eksponenciālā augšanā.

13. math.hypot(a, b)
Aprēķina taisnleņķa trijstūra hipotenūzu:
sqrt(a² + b²)

14. math.isfinite() / math.isinf()
Pārbauda vai skaitlis ir:

normāls (isfinite)
bezgalīgs (isinf)
(bieži lieto arī isnan — nav skaitlis)
15. math.comb(n, k)
Aprēķina kombināciju skaitu — cik veidos var izvēlēties k elementus no n bez atkārtošanās.
